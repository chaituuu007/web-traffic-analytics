# Web Traffic Analytics

> Web traffic, user engagement and conversion funnel analysis using Python.

## 📊 Project Overview

This project analyzes website traffic data to understand user engagement, traffic-source performance, conversion behavior, and potential drop-off points.

## 🎯 Objectives

- Calculate bounce rate
- Calculate average session duration
- Analyze pageviews per session
- Compare traffic sources
- Calculate conversion rate
- Identify pages associated with non-conversion
- Analyze device performance
- Provide actionable business recommendations

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- GitHub

## 📈 Key Metrics

| Metric | Result |
|---|---:|
| Sessions | 10 |
| Total Pageviews | 34 |
| Bounce Rate | 30% |
| Average Session Duration | 170.5 sec |
| Average Pageviews/Session | 3.4 |
| Conversion Rate | 50% |
| Engaged Sessions | 70% |

## 🔍 Key Findings

### Traffic Sources

Google Ads and Google Search achieved the highest observed conversion rates in this sample.

### User Engagement

The overall bounce rate was 30%, with an average session duration of 170.5 seconds.

### Device Performance

Mobile sessions showed a higher bounce rate than desktop sessions in the sample.

### Drop-off Analysis

Some content pages generated non-converting sessions, while pricing and contact pages had engaged visitors without conversions.

## 📊 Visualizations

The project includes:

- Conversion rate by traffic source
- Bounce rate by traffic source
- Session conversion funnel
- Device performance analysis

## 💡 Business Recommendations

1. Improve mobile landing-page experience.
2. Investigate high-performing acquisition channels.
3. Improve CTAs on content pages.
4. Review pricing and contact-page conversion journeys.
5. Implement sequential funnel event tracking.

## ⚠️ Dataset Limitation

This analysis uses a small sample of 10 sessions. Therefore, the observed percentages should be treated as directional rather than statistically generalizable.

A larger historical dataset should be used for robust business decisions.
